# Melbourne Split-Flap Clock — Open Sans

Separate Open Sans build of the Melbourne 3840 × 804 split-flap clock.

- Open Sans 600/700 via Google Fonts.
- Live time continues during the entrance animation.
- Unchanged HH/MM/SS flaps remain still.
- Portrait and landscape mobile preview scaling.
- Vanilla HTML, CSS and JavaScript for NVIDIA Shield signage playback.
- Search indexing blocked through metadata and `robots.txt`.

Query options: `?noanim=1`, `?noboot=1`, `?rotate=0`, or timezone/city overrides such as `?tz=Australia/Sydney&city=SYD`.
